# Portifólio — projeto Vite

## Estrutura
- index.html: estrutura da página.
- styles.css: aparência e responsividade.
- java.js: lógica, armazenamento, filtros, atividades e perfil.
- package.json: configura os comandos do Vite.

## Executar
1. Instale Node.js 20.19+ ou 22.12+.
2. Abra esta pasta no VS Code.
3. Abra o terminal.
4. Execute `npm install`.
5. Execute `npm run dev`.
6. Abra o endereço mostrado pelo terminal.

## Observação
As atividades, o nome e a foto do perfil são salvos no `localStorage` do navegador. Isso significa que os dados ficam neste navegador/computador e não em um banco de dados online.
